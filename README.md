# 纸页 · 纸质圣经阅读体验 Demo

一个围绕经文「空间位置记忆」设计的浏览器阅读原型。手机上可缩放、平移整本书；平板横屏可以看到完整的左右对开。

## 试用

GitHub Pages：https://xxmm1221.github.io/paper-bible-demo/

无需账号，无后端、无分析追踪。阅读位置只保存在当前浏览器本地。

## 已实现

- 全书固定原型排版：66 卷、1189 章、1254 个固定纸面页。屏幕变化只改变观看窗口，不重新排版。
- 左右对开与随阅读位置变化的书页厚度；底部显示全书位置。
- 单指慢拖平移，双指捏合缩放，双击放大 / 还原。
- 长按纸页任意位置约 0.36 秒，再向书脊方向慢拖：从抓取点到书脊之间弯起，下一页逐步露出。回拖可随时反向，松手后完成翻页或弹性回落。
- 真实的前页、纸背与下一页内容；动态弯曲明暗、柔和投影、纸边高光与多页快翻的薄层边缘。
- 「掀页演示」可自动演示掀开、停住偷看、再放回，演示结束页码不变。
- 单指快滑翻 1 页；双指同向快滑先翻 5 页，连续同向快滑加速到 10、20 页。
- 起手在实体左页时，仅向右快滑前翻；起手在实体右页时，仅向左快滑后翻。反方向只移动。
- 「看书侧」显示 66 卷简称标签，点击直接翻到对应书卷。
- 鼠标、键盘及桌面手势演示。

“翻 1 页”指翻动一张纸，切换到下一组对开；所以纸面页码前进 2。

## 体验边界

当前为参考小开本双栏风格的体验排版，不对应某一实体圣经的真实页码与行文。后续可接入获得使用授权的扫描页。翻页采用书脊约束、触点跟随的轻量曲面模型，并非完整纸张材料力学仿真。多指手势的速度阈值、移动系统边缘手势和触感仍需真机试用。

正常拖动在长按门槛之前超过 9px 即锁定平移，防止误掀页。掀页过程中加入第二根手指、取消触摸、切到书侧、窗口失焦或改变屏幕大小，均放回纸页而不误改页码。取消方向优先于跨过中点的惯性判定。

默认使用 WebGL 曲面网格；不支持 WebGL 时自动使用 Canvas 三角网格回退，仍保留可逆掀页而不是替换为滑动动画。纸面纹理按需缓存，字形使用页面已加载的本地字体资源。

## 本地运行与检查

无需安装依赖。目录内运行：

```sh
python -m http.server 8765 --bind 127.0.0.1
node --check app.js
node test-gestures.cjs
node test-paper-physics.cjs
node test-paper-interactions.cjs
```

然后打开本机 8765 端口。检查包括 92 项原有手势 / 固定版面检查、815 项曲面几何 / 释放 / 回落断言，以及 19 个实际输入控制器场景。输入控制器测试使用确定性时钟与渲染器替身，不冒充手机真机测试。
