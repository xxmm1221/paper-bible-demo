# 纸页 · 纸质圣经阅读体验 Demo

一个围绕经文「空间位置记忆」设计的浏览器阅读原型。手机上可缩放、平移整本书；平板横屏可以看到完整的左右对开。

## 试用

GitHub Pages：https://xxmm1221.github.io/paper-bible-demo/

无需账号，无后端、无分析追踪。阅读位置只保存在当前浏览器本地。

## 已实现

- 全书固定原型排版：66 卷、1189 章、1254 个固定纸面页。屏幕变化只改变观看窗口，不重新排版。
- 正文统一 13px 字号、14px 字格、18px 行距；普通空格沿用源数据的 0.35 格，全角空格保留一格。逐字用自然字形绘制，不横向拉伸文字或标点。章号使用原有独立 2.2 格位置，16px 字号；小节号上标。现有页、栏、行及经文内容不变。
- 静态 SVG 与翻页 Canvas/WebGL 纹理共用 `paper-typography.js` / `paper-page.js` 的文字坐标；字体子集加载后失效旧纹理缓存。
- 左右对开与守恒的纸张厚度：1254 个纸面对应 627 张纸，左右厚度由所在页码计算；侧面、底边、标签归属及翻页中途均跟随同一个模型，封皮不计入纸厚。犹大书对开右侧仅剩 11 张（约 1.8%），不会保留整本旧约索引。
- 单指慢拖平移，双指捏合缩放，双击放大 / 还原。
- 长按纸页任意位置约 0.36 秒，再向书脊方向慢拖：从抓取点到书脊之间弯起，下一页逐步露出。回拖可随时反向，松手后完成翻页或弹性回落。
- 真实的前页、纸背与下一页内容；动态弯曲明暗、柔和投影、纸边高光与多页快翻的薄层边缘。
- 「掀页演示」可自动演示掀开、停住偷看、再放回，演示结束页码不变。
- 单指快滑翻 1 页；双指同向快滑先翻 5 页，连续同向快滑加速到 10、20 页。
- 起手在实体左页时，仅向右快滑前翻；起手在实体右页时，仅向左快滑后翻。反方向只移动。
- 一镜到底的目录旅程：阅读 → 合书 → 转向纸边 → 聚焦切口 → 重新展开；途中返回反向衔接当前进度，不隐藏/替换书本舞台。
- 22 个错层半圆拇指切口，每组 3 卷；薄纸层、酒红皮封、旧约黑金/新约朱红标签。
- 物理/数字目录使用同一组 66 个节点，连续放大、移动、展开为可滚动列表；选择后先收回实体切口再开书。当前卷章节也通过同一路径打开。
- 手机全视口阅读，工具栏默认收起，轻点空白或「菜单」唤出，5 秒自动收起；工具是浮层，不挤占书页。
- 点击进入全屏；支持添加到主屏幕的 standalone manifest 与图标。浏览器地址栏由浏览器控制，网页不能强制隐藏；未注册离线缓存。
- 鼠标、键盘及桌面手势演示。

“翻 1 页”指翻动一张纸，切换到下一组对开；所以纸面页码前进 2。

## 体验边界

当前为参考小开本双栏风格的体验排版，不对应某一实体圣经的真实页码与行文。后续可接入获得使用授权的扫描页。翻页采用书脊约束、触点跟随的轻量曲面模型，并非完整纸张材料力学仿真。多指手势的速度阈值、移动系统边缘手势和触感仍需真机试用。

正常拖动在长按门槛之前超过 9px 即锁定平移，防止误掀页。掀页过程中加入第二根手指、取消触摸、切到书侧、窗口失焦或改变屏幕大小，均放回纸页而不误改页码。取消方向优先于跨过中点的惯性判定。

默认使用 WebGL 曲面网格；不支持 WebGL 时自动使用 Canvas 三角网格回退，仍保留可逆掀页而不是替换为滑动动画。纸面纹理按需缓存，字形使用页面已加载的本地字体资源。

## 一镜到底实现边界

双边合书、纸边特写与镜头为连续 3D CSS 场景，纸边展开为可操作的艺术化特写，不是扫描实物或完整纸张材料仿真。数字目录只改变标签的位置和尺寸；选卷只在合拢遮挡时提交新页码。场景摄影机从不写入阅读存档，中途返回恢复原缩放与位置。页面间的曲面掀页继续使用原有 WebGL/Canvas 模型。

本次纸张、半圆索引及黑红标签按用户提供的参考照片重建，未把该照片上传或放入公开仓库。

## 排版验收与版本识别

`type-2` 沿用逐字自然字形排版：不对正文或标点做横向拉伸。第 1175 页歌罗西书的「提摩太 / 节号 2」与「句号 / 节号 15」纳入专项回归，同样检查静态 SVG 和翻页 Canvas 纹理。原经文、分页和行列位置未改。

「阅读工具 → 关于」显示排版版本，并可主动「重新载入最新版」；入口带一次性刷新参数，页面脚本及样式统一带发布版本。不会自动打断阅读，不清除阅读位置或站点数据。旧的已打开页面仍须通过新入口或手动重新载入获取更新。

## physical-3：纸层、双边合拢与两根丝带

- 阅读页边改为同一条连续的细纸层轮廓，外侧圆角接到向书脊收拢的弧形底边。低对比、不等间距、略有间断；不再在薄侧边强行压扁完整书卷标签。纸张厚度仍从实际已翻/未翻纸量计算，独立皮封不计入纸厚。
- 左右纸块分别绕同一中轴同步合拢（±88°），不经过正面封面，不整体绕书转一圈；原目录标签沿页尖走到中间、展开为特写，数字目录仍复用同一批节点。选卷只在合拢后换页，再从该处双边展开。目录仍为艺术化放大的纸边特写，并非实体扫描或完整材料仿真。
- 主要入口是左右页边短按；慢拖仍平移，键盘可聚焦页边按钮。备用「书侧目录」收进工具菜单，不再常驻占画面。放大时允许把纸层及书签尾端完整拖入视口。
- 两根红色织纹丝带各自空槽起步，显式夹页/改夹/取出，保存经文所在对开及阅读缩放位置。当前页显示完整细带，其他页仅露尾；尾端有独立屏幕44px触控区。点击「回到书签」也走同一套合拢、定位、展开流程。
- 书签仅存当前浏览器的 localStorage，两槽独立；存储异常时降级为本次会话内记忆并提示。不是云同步，也不自动夹页。

回归新增双边角度/守恒、页边短按与拖动分流、书签闭合后提交、返回阅读姿态与取消导航，以及独立丝带存储/控制器和纸边几何测试。经文源文件与自然字形排版未改。
